This repository contains the CAD models and associated design files for betterdesk, a custom desk model
due to the sheer complexity of the model, we are unable to upload a stl or f3d or any other parametric model of this project
so, to obtain a parametric model, download the contents of this repository, open the folder 'table_stl_to_step' and click on 'convert_table.bat'
it will locally process and generate the step parametric file for you to view and use. 
credits to 2STEP Converter by yaneony
https://github.com/yaneony/2STEP-Converter.git
